# Programación I - ISTEA

Ejercicios resueltos de la materia Programación I, en Python.

## Organización

- **PracticaEnClase/**: ejercicios de la práctica en grupos (Unidades 2 y 3).
- **Unidad06/**: ejercicios de funciones.
- **Unidad07/**: ejercicios de listas.
  - `simple_XX_...`: nivel simple.
  - `medio_XX_...`: nivel medio.

La numeración de cada archivo sigue la de los enunciados de la cátedra,
y cada archivo tiene el enunciado al principio como comentario.

## Cómo ejecutarlos

Desde la carpeta del repositorio:

    python Unidad07/simple_01_cargar_numeros.py

Probado con Python 3.14.
